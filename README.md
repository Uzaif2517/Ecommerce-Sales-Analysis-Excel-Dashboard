# Ecommerce Sales Analysis Dashboard

## Project Overview

This project presents an interactive **Ecommerce Sales Analysis Dashboard** created using Microsoft Excel. The dashboard analyzes ecommerce sales data and provides insights into sales performance, profitability, orders, quantity sold, product categories, and geographical performance.

The objective of this project is to transform raw ecommerce sales data into meaningful business insights using Excel data analysis and visualization techniques.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Slicers
* KPI Cards
* Data Visualization

## Dataset

The dataset contains approximately **9,994 sales records** with information such as:

* Order ID
* Order Date
* Ship Date
* Ship Mode
* Customer Name
* Customer Segment
* Country
* City
* State
* Region
* Product Category
* Product Sub-Category
* Sales
* Quantity
* Discount
* Profit

## Dashboard KPIs

The dashboard tracks important business metrics including:

* Total Sales
* Total Profit
* Total Quantity Sold
* Total Orders
* Profit Margin
* Year-over-Year Growth

## Analysis Performed

### Sales and Profit Analysis

Monthly sales and profit trends were analyzed to understand business performance throughout the year.

### Year-over-Year Analysis

The dashboard compares yearly performance to identify growth in:

* Sales
* Profit
* Quantity
* Orders
* Profit Margin

### Category Analysis

Sales and profit performance were analyzed across major product categories:

* Furniture
* Office Supplies
* Technology

### Top 5 Sub-Categories

The dashboard identifies the highest-performing product sub-categories based on sales.

### Geographic Analysis

State-wise sales performance was analyzed to understand which locations contribute the most to overall revenue.

The main objective of this project is to demonstrate how Excel can be used to analyze ecommerce data and create an interactive business intelligence dashboard that helps stakeholders make data-driven decisions.
